那让我写写此时此刻我内心真实所想的思绪吧，想到哪写到哪，既是交由你看，也是梳理我自己的心情。



对我来说，产生好感更多地看的是对方符合我审美的点，不仅仅是外貌身段；同时也赞美你的善良，会在和阿姨吵架后愧疚反思自己过分而扁扁地去洗碗；赞美你的性格，会及时地肯定对方的付出和存在的意义；赞美你的诚实，我对说谎很敏感但和你的相处中能够安心。好感在随着更多的相处而上升。

而喜欢也一定是过程的产物，但发觉自己正喜欢对方，却只需要一个瞬间。并在这样的瞬间之后，就无法再用对方人还不错，对她有好感来欺骗自己。

而我是哪一个瞬间察觉到自己正喜欢着你呢？很遗憾甚至不如产生好感的点滴日常温情瞬间，反而是伴随着各种各样的负面情绪。



所以对我来说，让我下更多功夫的不是喜欢上你，而是在明知道喜欢的同时，不惊扰到你。当然这一点我一开始做的很差hh。

在冷静的时候给自己以下建议

0-原则上，我来协助对方解决问题，而不是给对方添新的问题。最差的结局不要质问对方。

1-在对方难过的时候，不要“索要情绪价值”，不要“确认对方内心我是否重要”，不要“试探对方让她当下做出选择”，不要“追问为什么”。

2-明确这是对方的课题，我无法帮上忙，不要试图说服对方，不要加以自己的价值观与对方，不要表示不理解。

3-对方难过时也许需要陪伴，但未必对我这个客体有倾诉的欲望，允许沉默，允许对方难以启齿，允许对方消失。

4-如果因为此问题使聊天进入冷冻，翻出来阅读并注意以下
4.0-一定要保持冷静，不要被对方带动情绪进行消极思考从而否定对方对自己的好感。
4.1-让她静静，但不是我也后退，也沉默，或者不理对方。尽可能不要让她产生“是我让气氛变差了”，只会新增一层阴霾。
4.2-永远允许对方不向自己解释这件事情，不下追，不用打起精神陪我聊，即使在场，也不要打探。
4.3-不要认为沉默是尴尬，沉默有时不意味着产生裂缝，并非需要在此时有所输出。保持陪伴状态即可。
